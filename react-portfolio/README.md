# Devika K G - Portfolio

A modern, animated portfolio website built with React and Framer Motion, showcasing my skills, projects, and achievements as an AI/ML and Full Stack Developer.

## ✨ Features

- **Modern Design**: Sleek dark theme with gold accents and gradient effects
- **Smooth Animations**: Powered by Framer Motion for fluid page transitions and interactions
- **Glassmorphism**: Modern UI design with frosted glass effects
- **Responsive**: Fully responsive design that works on all devices
- **Interactive Elements**: Hover effects, scroll animations, and micro-interactions
- **SEO Optimized**: Proper meta tags and semantic HTML

## 🚀 Technologies Used

- **React** - UI library
- **Vite** - Build tool and dev server
- **Framer Motion** - Animation library
- **React Icons** - Icon library
- **CSS3** - Styling with custom properties and animations

## 📦 Installation

1. Navigate to the project directory:
```bash
cd react-portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and visit: `http://localhost:5173`

The portfolio is fully responsive with breakpoints at:
- Desktop: 1200px+

- Mobile: < 768px

## 🔧 Customization

To customize the portfolio for your own use:

1. **Update Personal Information**:
   - Edit `src/components/Hero.jsx` for name and title
   - Edit `src/components/Contact.jsx` for contact details

2. **Modify Projects**:
   - Edit the `projects` array in `src/components/Projects.jsx`

3. **Change Skills**:
   - Edit the `skills` array in `src/components/Skills.jsx`

4. **Update Colors**:
   - Modify CSS custom properties in `src/index.css`

5. **Replace Resume**:
   - Add your resume PDF to `public/` folder
